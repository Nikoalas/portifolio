Ferramentas que construí

Bancada de PDF

Problema
Documentos digitalizados de centenas de MB lotavam o armazenamento e dificultavam o envio e o protocolo. Serviços online exigiriam mandar documentos sensíveis para servidores de terceiros.
Solução
Uma página que reduz o PDF direto no navegador: o arquivo nunca sai do computador. Preserva o texto, limpa metadados e avisa quando o PDF parece assinado digitalmente, já que comprimir pode invalidar a assinatura.
Feito com
JavaScript puro, HTML e CSS

Gerador de QR Code

Problema
Muitos idosos atendidos no cartório tinham dificuldade com o ambiente digital, e os sites que geravam QR Code eram pagos.
Solução
Um script curto: cola o endereço de um site e ele gera o QR Code correspondente.
Feito com
Python e a biblioteca qrcode
